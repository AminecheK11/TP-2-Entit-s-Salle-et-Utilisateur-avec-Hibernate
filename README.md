# TP 2 - Gestion des Salles et Utilisateurs avec Hibernate

## Description
Ce projet a pour objectif d'appliquer les concepts de JPA et Hibernate pour la gestion des données.

Il permet de gérer :
- les utilisateurs
- les salles
- les opérations CRUD
